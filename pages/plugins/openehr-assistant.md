# openEHR Assistant

Install id `openehr-assistant`. Use it when an assistant should author or review openEHR archetypes, templates, compositions, or AQL, or search CKM and the specifications.

```text
/plugin install openehr-assistant@cadasto
```

[Add the marketplace](../quick-start.md) first. The build fetches the README below from `Cadasto/openehr-assistant-plugin` at the tag this catalog pins.
