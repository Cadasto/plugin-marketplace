# openEHR Assistant Dev

Install id `openehr-assistant-dev`. Use it when you are adding guides, MCP tools, examples, or releases to the openEHR Assistant server or plugin.

```text
/plugin install openehr-assistant-dev@cadasto
```

[Add the marketplace](../quick-start.md) first. Clinical modelling is [`openehr-assistant`](openehr-assistant.md). The build fetches the README below from `Cadasto/openehr-assistant-dev-plugin` at the tag this catalog pins.
